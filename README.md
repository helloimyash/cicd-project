\# CI/CD Pipeline Using GitHub Actions



\## About

This is a beginner-friendly Cloud \& DevOps project to learn how CI/CD automates software workflows using Git, GitHub, and GitHub Actions.



\## What Is CI/CD?

\- \*\*CI (Continuous Integration):\*\* Automatically checks code changes.

\- \*\*CD (Continuous Delivery/Deployment):\*\* Automates preparing or releasing software.



\## Technologies Used

\- Git \& GitHub

\- GitHub Actions

\- YAML

\- PowerShell



\## How It Works

1\. Write or update code locally.

2\. Commit and push changes to GitHub.

3\. GitHub Actions runs the configured workflow.

4\. Check the workflow results in the Actions tab.



\## Project Structure

```text

cicd-project/

├── .github/

│   └── workflows/

│       └── ci.yml

└── README.md

```



\## Learning Goals

\- Understand CI/CD fundamentals.

\- Automate tasks using GitHub Actions.

\- Learn workflow configuration and troubleshooting.
